# Smart Library Seat Management System

## Project Context
We are planning to build a smart **Library Seat Management System** for our college library.

### Core Problem
Students currently have to physically roam around the library to find an empty seat. At the same time, many students leave the library temporarily for lunch, calls, washroom breaks, etc. but keep their bags/books on their seats for long periods, effectively blocking those seats for other students.

The goal is to create a system that provides **real-time visibility and controlled management of library seating**, while making seat usage fair and efficient.
